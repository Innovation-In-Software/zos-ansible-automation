# Lab 7: USS quick and dirty intro

Goals:

1. Access USS on z/OS via omvs.
2. Learn a few basic commands.
3. Explore your home directory.

Overview:

We assume you are a z/OS system programmer with experience on the "MVS side" of z/OS. It's possible you haven't used USS before. If that's the case, this lab will provide a very brief overview and introduction. The relevance to Ansible is that Ansible accesses z/OS by using a secure shell connection into the USS environment.

This lab can be done as a group with the instructor's guidance.

If you are already familiar with USS, you can skip this lab.
